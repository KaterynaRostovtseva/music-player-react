# 🎧 Audio Player Web Application

📂 GitHub: https://github.com/KaterynaRostovtseva/music-player-react
🌐 Live: https://music-player-reac.vercel.app/

Interactive web application for listening to music with playlist management and audio visualization.

---

## 🚀 Features

### ✨ User Features
- User profile editing (upload avatar, change nickname and password)  
- Create, edit, and delete playlists  
- Add and remove tracks from playlists  
- Drag and drop tracks to reorder playlists  
- Track search functionality  
- Audio playback controls (play, pause, previous, next, volume)  
- Audio visualizer synchronized with playback  

### 📱 UI & UX
- Modern and user-friendly interface  
- Optimized for desktop devices  
- Smooth drag-and-drop interactions  

---

## 🧰 Tech Stack

| Technology | Purpose |
|--------|--------|
| React | UI library |
| Redux Toolkit | State management |
| Material-UI (MUI) | UI components |
| Web Audio API | Audio processing and visualization |
| react-beautiful-dnd | Drag and drop functionality |

---

## ▶️ Getting Started

### 1. Clone the repository

git clone https://github.com/KaterynaRostovtseva/music-player-react.git

cd music-player-react

### 2. Install dependencies
npm install

### 3. Run the project
npm start

The app will be available at:

http://localhost:3000
